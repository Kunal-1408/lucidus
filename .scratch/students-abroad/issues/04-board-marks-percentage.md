# 04: Board marks on Indian boards (percentage)

**What to build:** "Latest exam marks" is replaced by Board marks. The board list becomes CBSE, CISCE, State board, Cambridge/UK, IB, US high school, Other. Each class sees only the board results it has (the grid), with boards-upcoming moved next to the marks; a Class 12 Student with boards upcoming enters an expected result. This ticket handles the percentage scale used by Indian boards; other scales come in 05.

See spec: "Which questions appear (the grid)", glossary term Board marks.

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [x] Profile gains a Class 10 result and a Class 12 result, each `{ scale, value }`, with only the percentage scale for now; `latestMarks` stays readable until ticket 09
- [x] Rules module implements the grid: Class 9 none; Class 10 gets the Class 10 result only once boards are done; Class 11 the Class 10 result; Class 12 both, the Class 12 one labelled "Expected Class 12 result (pre-boards or predicted)" while boards are upcoming; boards-upcoming only for Class 10 and 12; class not given shows both results and no boards-upcoming
- [x] Changing class clears answers the grid rules out; a percentage outside 0–100 is refused
- [x] Boards-upcoming is a Core field placed next to the marks; form order follows the spec
- [x] Saved Profiles drop `latestMarks` on load
- [x] Extraction produces Class 10 and Class 12 result Criteria; marks for any other year (for example NMMS's Class 7/8) become Extra requirements
- [x] Within reach marks Goals keep today's rule (boards upcoming, gap ≤ 5) on both results

Criteria and matching: a result Criterion is `gte`, changeable, and its value is a `BoardResult` too, so the scale travels with it (`normaliseValue` → `toBoardResult`). The Matcher (`compareBoardResult`) judges only on the same scale and is unknown otherwise; missing labels are "Class 10 result" / "Class 12 result". The Goal rule (`boardMarksGoal`) is today's (boards upcoming, gap of at most 5, percentage) applied to the result whose boards are upcoming: a Class 12 Student's Class 10 result is final, so no Goal on it. Ticket 05: add a scale to `ResultScale`, `RESULT_SCALES`, `SCALE_RANGES` and `RESULT_SCALE_RANGES`, teach `toBoardResult` to read it, and extend `boardMarksGoal` for IB points; ticket 08 can reuse the same `{ scale, value }` shape only if ATAR/SAT need scales, otherwise plain `numberBetween` fields.

Extraction (`ingestion/extraction-rules.ts`): `marksThresholds` finds each minimum percentage and the year it names (`marksYear`: the first year after the percentage, else the last before; SSC/matric = 10, HSC/Higher Secondary/Senior Secondary/10+2 = 12). Marks naming no year give nothing from the rules and are left to the LLM, whose guide now asks for the two results and says other-year marks are extra requirements. Selection-test cut-offs are still skipped.
